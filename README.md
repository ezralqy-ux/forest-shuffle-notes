几个朋友一起积累的《森森不息》实战经验。目标是在 Board Game Arena 上提高胜率和竞技分数，不只追求单局高分。

默认配置：**本体＋阿尔卑斯＋林地边缘**。人数不作默认：具体经验和复盘涉及人数差异时请注明，尤其不要把双人对抗经验直接套到多人局。

## 怎么一起维护

有经验就直接改对应文章，或提 PR 留言讨论。每条尽量写清“建议怎么打、什么情况下适用、有什么例外”。有分歧就保留不同意见，用对局继续验证。

复盘记录 BGA 对局链接和关键选择；得出有用结论后，补进对应策略文章。无需额外的投稿流程。

首批内容整理自伙伴提供的经验，卡牌指代已由仓库发起者确认。强度排序、分数估计和行动阈值仍是玩家观点，不代表已验证的最优解；编辑补充的边界和分析也有待实战检验。

正文使用中文名称，必要时保留俗称。部分名称采用中文通用译名，尚未逐一核对 BGA 当前中文显示；遇到不同译名可直接在原文修正，不单独维护术语表。

## 目前值得验证

- 先手没有花旗松时，“8张牌就种树”的适用局面与人数。
- 狼在“牌堆剩49张”附近的加速价值；原经验中的49张口径也需确认。
- 野猪的“2×2”具体指什么组合，以及“母猪只有3张”的计数口径。
- 石貂后期值得留几张，什么时候应该提前打出。
- 重复种类的蝴蝶用于过牌时，是否真的有利于当前胜负。

规则发生争议时查阅[出版商规则与卡牌附录](https://www.lookout-spiele.de/en/games/forrestshuffle.html)，这里专注实战经验。
